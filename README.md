# 📚 Old Books Platform (Full-Stack Next.js App)

A full-stack website built with Next.js for sharing, discovering, and managing vintage/old books. This project serves as a complete CRUD system featuring robust authentication and user-specific favorites management.

## ✨ Features

- **Authentication System:** Secure user sign-up, sign-in, and session management powered by **Better Auth**.
- **Book Management (CRUD):** 
  - Browse all listed vintage books.
  - Add new books with details (title, description, location).
  - Clean and responsive UI built for book lovers.
- **Favorites System:** Authenticated users can save/remove books to/from their personal favorites list.
- **Internationalization (i18n):** Multi-language support for seamless localization.
- **Modern Tech Stack:** Leveraging the latest Next.js App Router and server actions.

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Database & ORM:** [Prisma ORM](https://www.prisma.io/)
- **Authentication:** [Better Auth](https://www.better-auth.com/)
- **Styling:** Tailwind CSS
- **Language:** TypeScript
